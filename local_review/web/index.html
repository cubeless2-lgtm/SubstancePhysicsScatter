최종 배치는 검증된 render revision을 유지합니다. Hull은 실제 Jolt Create 결과이고 visual mesh와 다를 수 있습니다. 단일 convex collider입니다.
준비된 재질은 실제 N2의 7개 지도를 생성합니다. 재질 미완료 자산은 H/N/C만 생성하며 PBR로 표시하지 않습니다. Saved 재베이크는 저장 pose·Mask를 사용합니다. 물리 설정 변경은 새 Simulate가 필요합니다. Saved Hull은 검증된 실제 Simulate 출처를 재사용하며 신뢰할 출처가 없으면 표시하지 않습니다. normal map이 없으면 geometric fallback입니다. 수동 텍스처는 512² 불투명 UV0의 BC/R/M/Normal 4역할만 지원하며 임의 DCC shader는 재현하지 않습니다.
